Агрегирование временного ряда
Задача
Привести ряд с шагом 3 часа к более крупным интервалам.

Вход
{
  "dataset": {
    "timestamps": [
      "2016-01-01T00:00:00",
      "2016-01-01T02:00:00",
      "2016-01-02T02:00:00",
      "2016-01-03T02:00:00"
    ],
    "values": {
      "temperature_c": [2.0, null, null, 6.0]
    }
  },
  "method": "mean",
  "parameters": {"interval": "1d"}
}
method: mean, min, max или sum. parameters.interval
обязателен; в проверке используется "1d".

Правила
Окна привязаны к календарным границам местного времени: суточное окно
[00:00; 00:00 следующих суток).
Окно существует, если в нём есть хотя бы одна метка времени;
неполное окно допустимо.
В результат записывается начало окна в формате YYYY-MM-DDTHH:MM:SS.
null не участвует в вычислении. Если все значения переменной в окне
null, в строке этого окна для неё null.
Метки результата строго возрастают; вход считается возрастающим,
дубликаты меток не проверяются.
Пустой вход даёт пустой ответ: {"timestamps": [], "values": {}}.
Выход
Ответ — объект ровно с timestamps и values:

{
  "timestamps": [
    "2016-01-01T00:00:00",
    "2016-01-02T00:00:00",
    "2016-01-03T00:00:00"
  ],
  "values": {
    "temperature_c": [2.0, null, 6.0]
  }
}
