Требования к участнику
Кто участвует
Конкурс проводится в двух группах:

школьники;
студенты.
Группу назначает организатор. От группы зависит набор доступных
заданий и итоговая формула баллов.

Задания разбиты на три уровня — от базового к проектному. Подробное
описание конкретных заданий появляется на странице задачи после старта.

Что нужно знать
основы программирования на Python;
чтение и запись файлов, кодировка UTF-8;
формат JSON;
списки, словари, циклы, ветвления и функции;
базовые математические операции и работа с числами;
сравнение дробных чисел с небольшим допуском.
Для отдельных заданий могут понадобиться дополнительные темы — они
будут указаны в условии задачи.

Среда
автоматические задания проверяются на Python 3.12;
итоговый проект — Python 3.11+;
на один тест: до 10 секунд и 1 ГБ памяти;
размер архива решения — до 10 МБ.
Список разрешённых библиотек и правила оформления — в разделе
«Правила оформления».

Как оценивается
автоматическое задание: доля пройденных тестов;
задание с ручной проверкой: оценка по критериям из условия;
итоговый балл считается отдельно для каждой группы;
места, дипломы и сертификаты описаны на странице «Зачёт».
Что не оценивается
скорость сверх установленного лимита;
стиль кода в автоматических заданиях;
объём данных больше указанного в условии.

Правила оформления решения
Это общие правила для всех заданий. Если в условии конкретной задачи
написано иначе, приоритет у условия задачи.

Решение
решение — программа на Python;
автоматические задания запускаются в фиксированной среде;
программа читает input.json и записывает результат в output.json;
для отдельных заданий результат может быть отдельным файлом — это
указано в условии;
файлы должны быть в кодировке UTF-8.
Формат ответа
в output.json должен быть один JSON-объект;
порядок ключей и пробелы не важны;
лишние ключи запрещены: в ответе должны быть только поля,
описанные в условии;
числа записываются числами, а не строками;
целые и дробные числа допустимы; булевы значения числом не считаются;
null означает пропуск и остаётся null, если условие не требует
обратного;
дробные числа сравниваются с допуском 1e-6.
Метки времени
Метки времени возвращаются в том же виде, в котором пришли во входных
данных. Не добавляйте часы и часовой пояс, не переводите в UTC и не
меняйте формат без требования в условии.

Ошибки
Если условие задачи требует обработки некорректного входа, используйте
формат, указанный в условии. Не оставляйте необработанный трейсбек.

Архив
Для автоматических заданий принимается ZIP:

solution.py
requirements.txt
requirements.txt обязателен даже без сторонних библиотек — создайте
пустой файл. Дополнительные файлы и вложенная папка допустимы, если это
не запрещено условием.

Зависимости
Для автоматических заданий разрешены только:

numpy==2.0.0
pandas==2.2.3
scipy==1.14.1
openpyxl==3.1.5
Другие сторонние пакеты запрещены. Для итогового проекта ограничений по
пакетам PyPI нет, но версии следует фиксировать в requirements.txt.

Подробности
Конкретные поля входа и выхода, имена файлов и особые случаи описаны
в условии каждой задачи. Общие правила зачёта — на странице «Зачёт».

Как сдавать решения
Общая инструкция: что скачать, как собрать архив и куда его загрузить.

1. Откройте задание
После старта конкурса на странице задачи будут:

условие (с примером входа и выхода);
материалы или архив тестов;
форма загрузки решения.
Скачайте материалы до начала работы. Подробности формата — в условии
задачи и в «Правилах оформления».

2. Решите задачу
Создайте папку solution/:

solution/
├── solution.py
├── requirements.txt
└── README.md          # необязательно
solution.py читает input.json и записывает output.json. Если
условие требует другой файл результата, используйте имя из условия.

requirements.txt обязателен. Если сторонние библиотеки не нужны,
оставьте файл пустым.

3. Соберите ZIP
Для автоматических заданий принимается ZIP с solution.py и
requirements.txt. Вложенная папка допустима.

Не добавляйте в архив:

input.json, output.json и скачанные тесты;
myenv/, .venv/, __pycache__/;
большие данные и лишние файлы.
Максимальный размер архива — 10 МБ.

4. Загрузите
Откройте страницу задачи.
Выберите ZIP.
Нажмите «Сохранить решение».
Дождитесь сообщения «Решение сохранено».
На задачу принимается одна сдача: новая загрузка заменяет предыдущую.
После окончания конкурса загрузка закрывается.

5. Проверьте результат
На странице задачи должно появиться «Решение сдано». Если отметки нет,
загрузка не прошла: прочитайте сообщение и повторите.

Баллы автоматических заданий появляются после проверки организатором.
Итоги и награды публикуются после окончания конкурса.

Проект (третий уровень)
Проект сдаётся отдельным ZIP-архивом до 10 МБ:

app/                  # код, точка входа app/main.py
tests/                # pytest-тесты
README.md             # точная команда запуска
requirements.txt      # зависимости
REPORT.md             # что сделано и что ограничено
examples/             # по желанию
Dockerfile            # по желанию
Не включайте .venv/, myenv/, __pycache__/, данные и секреты.
Ссылка на GitHub не принимается — нужен ZIP.

Проверка ручная: чистое окружение Python 3.12, pip install -r requirements.txt, pytest -q, запуск по README, /health, /docs,
несколько запросов и защита. Баллы выставляются по рубрике из условия.

Ограничения
Что	Значение
Python для автоматических заданий	3.12
Время на тест	10 секунд
Память на тест	1 ГБ
Размер ZIP	10 МБ
Частые ошибки
Сообщение	Что делать
«Файл слишком большой»	уменьшите архив
«Недопустимое расширение»	загрузите ZIP
«Нет solution.py»	положите файл в корень архива
«Нет requirements.txt»	создайте файл, даже пустой
«Пакет не разрешён»	проверьте список библиотек
«Превышено время»	оптимизируйте решение

баллы, места и призы — на странице «Зачёт»;
вопросы — организатору конкурса.
