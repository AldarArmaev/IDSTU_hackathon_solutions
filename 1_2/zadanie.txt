Заполнение пропусков временного ряда
Задача
Заполнить null в выбранных числовых переменных, не меняя временные
метки, известные значения и остальные переменные.

Вход
{
  "dataset": {
    "timestamps": [
      "2016-01-01T02:00:00",
      "2016-01-01T05:00:00",
      "2016-01-01T15:00:00"
    ],
    "values": {
      "temperature_c": [0.0, null, 13.0],
      "wind_speed_ms": [1.0, 2.0, 3.0]
    }
  },
  "method": "linear",
  "parameters": {}
}
method — один из методов ниже.

Методы
method	Действие	parameters
constant	заменить null числом	{"value": 0}
ffill	последним известным значением слева	{}
bfill	ближайшим известным значением справа	{}
linear	линейная интерполяция по времени	{}
parameters.value — число для constant; если поле не указано,
используется 0.
parameters.variables — необязательный список имён. Если поля нет,
обрабатываются все переменные; если список пуст — ни одна; имя,
которого нет в values, — ошибка структуры.
Линейная интерполяция считается по фактическим меткам времени, а не
по номерам элементов; шаг может быть неравномерным.
Если для метода нет опорной точки (например, ffill для пропуска в
начале или linear на краю), оставьте null.
Выход
Ответ — объект ровно с timestamps и values:

{
  "timestamps": [
    "2016-01-01T02:00:00",
    "2016-01-01T05:00:00",
    "2016-01-01T15:00:00"
  ],
  "values": {
    "temperature_c": [0.0, 3.0, 13.0],
    "wind_speed_ms": [1.0, 2.0, 3.0]
  }
}
Все переменные входа присутствуют, включая необработанные. Известные
значения и метки не меняются.

При неизвестном имени в parameters.variables верните
{"status":"error","message":"format data error"}.
